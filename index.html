MarkTML

Markdown, translated: type short, save standard Markdown, with HTML only where Markdown falls short.

MarkTML is a Markdown editor for the Mac. You type short, memorable marks such as _…_ or <blue>…</blue>. It saves an ordinary .md file with standard Markdown and HTML, which browsers, Obsidian and Typora display correctly. While you edit, marks appear only at the cursor; everything else looks finished.

To try every element, choose Help › Open Sample Document.

MarkTML requires macOS 26 or later. It is tested on Macs with Apple silicon, not on Intel Macs.

“Markdown Standard” mode

If you prefer the usual Markdown, choose this mode in Settings. Then *…* and _…_ mean italic, **…** and __…__ mean bold. Underline with ⌘U, double underline with ⌘⇧U.

While typing

MarkTML adds closing marks and brackets for you and wraps a selection. You can turn this off in Settings.

- turns into a bullet at once. ⇥ and ⇧⇥ indent list lines and change the level of headings. Insert tables with the grid in the toolbar or with Format › Table…

Font

Choose the typeface and size in Settings. Both apply to the text on the left, headings scale with it, and code stays monospaced. The right side stays monospaced and only follows the size. Neither the file nor the export changes.

Outlining
KeysAction
⌃⌘↑ ⌃⌘↓Move a line and its sub-lines up or down
⌃⌘← ⌃⌘→Collapse or expand sub-lines; this affects the window only, not the file

Shortcuts
KeysAction
⌘ESwitch between view and edit
⇧⌘EShow or hide the right pane with the saved form
⌘KInsert a link
⌘CCopy with formatting; plain text editors receive the saved form

Right pane

The right pane shows the same file in its long form. With “Edit” checked you can type there too: the text on the right becomes the file at once, and the left side follows a moment later.

When you type in one field, the other jumps so that the edited line sits at the same height on both sides.

With the Full HTML checkbox, the pane shows the whole text as HTML, read-only. The file stays Markdown; images appear as references, private notes are left out.

Images and files

Images and file links are found relative to the document’s folder. Files you drag in go to the subfolder Attachments. MarkTML asks for access once per folder. Click a file link for Quick Look, double-click to open it.

Export

File › Export offers .docx, .rtf, .rtfd, .txt, .odt, PDF, HTML and .opml. Private notes are always left out. Images are kept in .docx, .rtfd, PDF and HTML; .odt and .rtf show the file name instead.
